## Source-code provenance
The sketch in `src/cache_mapping.ino` is a **reference implementation reconstructed from the pin assignments and behaviour described in the project discussion**. It is not claimed to be byte-for-byte identical to the earlier sketch used during the original build. The project owner should compare it with the tested local sketch and verify the complete hardware behaviour before treating it as the final tested source.

The project owner should review the code, confirm wiring against the physical build, run the testing checklist and update test observations. AI assistance does not replace hardware validation or authorship review.
