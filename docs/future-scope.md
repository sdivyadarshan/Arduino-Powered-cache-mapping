# Future Scope

Possible extensions, if the hardware and project objective are expanded:

- Multiple cache entries instead of one stored value.
- Direct-mapped cache demonstration with tag, index and offset fields.
- Set-associative and fully associative lookup modes.
- FIFO or LRU replacement-policy simulation.
- Separate simulated main memory and cache refill behaviour on a miss.
- Hit/miss counters and calculated hit ratio.
- A controlled timing demonstration that distinguishes simulated delay from real processor memory latency.
